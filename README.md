# deep-dune-kit

Frontend developer · TypeScript and React

给自己省点事的小工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/deep-dune-kit.git
cd deep-dune-kit
chmod +x run.sh
```

## 备注

就是给自己省点事，没做太多抽象。
